### **Roadmap: Программа для транскрибации голоса в текст по горячей клавише**

---

#### **Ключевая идея:**
Создать фоновое приложение для Windows 10/11, которое находится в системном трее. По нажатию настраиваемой глобальной горячей клавиши оно записывает голос, преобразует его в текст с помощью локальной модели и вставляет этот текст в активное поле ввода, где находится курсор.

#### **Технологический стек (предлагаемый):**
*   **Язык программирования:** Python (отлично подходит для работы с аудио, UI и моделями машинного обучения).
*   **Системный трей и UI:** `pystray` для иконки в трее, `tkinter` или `PyQt6` для окна настроек.
*   **Глобальные горячие клавиши:** `pynput` или `keyboard`.
*   **Запись аудио:** `sounddevice` или `pyaudio`.
*   **Локальная транскрибация:** **OpenAI Whisper**. Это самая мощная и популярная модель, которая может работать полностью оффлайн и поддерживает множество языков, включая русский и английский.

---

### **Этапы разработки:**

#### **Этап 1: Ядро функциональности (MVP - Minimum Viable Product)**
*Цель: Создать скрипт, который выполняет основную цепочку действий.*

1.  **Запись аудио:**
    *   Написать функцию, которая активируется, записывает аудио с микрофона по умолчанию и сохраняет его во временный файл (например, `output.wav`).
2.  **Интеграция модели транскрибации:**
    *   Установить Whisper (`pip install openai-whisper`).
    *   Написать функцию, которая загружает локальную модель (например, `base` или `small` для начала) и транскрибирует аудиофайл, полученный на шаге 1.
    *   Вывести распознанный текст в консоль.
3.  **Связка записи и транскрибации:**
    *   Объединить обе функции в один скрипт: запуск -> запись -> сохранение -> транскрибация -> вывод в консоль.

#### **Этап 2: Интеграция с операционной системой**
*Цель: Сделать скрипт удобным для использования в любой программе.*

1.  **Глобальная горячая клавиша:**
    *   Используя `pynput`, создать "слушателя" клавиатуры, который будет работать в фоне.
    *   Настроить его на срабатывание по сочетанию клавиш (например, `Left Shift + Left Ctrl`). При срабатывании запускается процесс с Этапа 1.
2.  **Вставка текста:**
    *   Вместо вывода текста в консоль, использовать библиотеку `pyperclip` для копирования текста в буфер обмена.
    *   Сразу после копирования, с помощью `pynput.keyboard` эмулировать нажатие `Ctrl + V` для вставки текста в активное поле.
3.  **Выбор языка:**
    *   Реализовать простейший механизм переключения языка (Русский/Английский), который передается в модель Whisper. Например, по разным горячим клавишам или через изменение переменной в коде.

#### **Этап 3: Создание полноценного приложения**
*Цель: Превратить скрипт в удобное приложение с настройками.*

1.  **Иконка в системном трее:**
    *   С помощью `pystray` создать иконку, которая будет постоянно висеть в трее.
    *   Добавить контекстное меню для иконки с пунктами: "Настройки", "Пауза/Возобновить" и "Выход".
2.  **Файл конфигурации:**
    *   Создать файл `settings.ini` или `config.json` для хранения настроек:
        *   Выбранное сочетание горячих клавиш.
        *   Язык по умолчанию.
        *   Выбранная модель Whisper (`tiny`, `base`, `small`, `medium`).
3.  **Визуальная обратная связь:**
    *   Реализовать смену иконки в трее во время записи голоса (например, с обычной на красную), чтобы пользователь понимал, что его слушают.
4.  **Окно настроек (опционально, но желательно):**
    *   Создать простое окно на `tkinter` или `PyQt`, где пользователь сможет графически изменять горячие клавиши и другие параметры из файла конфигурации.

#### **Этап 4: Упаковка и оптимизация**
*Цель: Сделать приложение готовым к распространению и улучшить его работу.*

1.  **Упаковка в `.exe`:**
    *   Использовать `PyInstaller` или `cx_Freeze`, чтобы собрать все скрипты и зависимости в один исполняемый файл (`.exe`). Это позволит запускать программу на любом компьютере с Windows без установки Python.
2.  **Оптимизация производительности:**
    *   Исследовать возможность транскрибации "на лету" (streaming), без сохранения в промежуточный файл, для уменьшения задержки.
    *   Дать пользователю выбор размера модели Whisper в настройках, объяснив компромисс между скоростью и точностью.
3.  **Автозапуск:**
    *   Добавить в установщик или в настройки приложения опцию "Запускать при старте Windows".
4.  **Обработка ошибок:**
    *   Добавить обработку ситуаций, когда микрофон не найден, модель не может быть загружена и т.д., с уведомлением пользователя.
